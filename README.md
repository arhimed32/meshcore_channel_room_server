# MeshCore Channel Room Server для Heltec LoRa 32 V4

Модифицированная прошивка MeshCore 1.17.1 сервера комнат (**Room Server**) для платы **Heltec WiFi LoRa 32 V4** (ESP32-S3 + SX1262 + OLED SSD1306) с функцией автоматического прослушивания приватных/публичных каналов и ретрансляции сообщений в комнату.

---

## 🚀 Новые возможности

1. **Прослушивание любых приватных и публичных каналов:**
   - Комнатный сервер может параллельно слушать до 8 групп/каналов MeshCore (настраиваются через CLI).
   - Поддерживаются 128-битные и 256-битные ключи в форматах **Base64** и **HEX**, а также ключевые слова `default` / `public`.
   - Вся конфигурация каналов сохраняется в энергонезависимой памяти Flash (`/channels.dat`) и не сбрасывается при перезагрузке.

2. **Привязка авторства к реальному пользователю:**
   - Сообщения из канала публикуются в комнату **от имени реального отправителя** (его публичного ключа), а не от обезличенного сервера `Heltec Room`.
   - Клиенты, у которых отправитель записан в контактах (например, `Olejan H1` или `Olejan M`), видят его привычное имя и аватар.

3. **Корректная обработка эха (Self-Echo Suppression):**
   - Автор сообщения в канале при входе в комнату **не получает дубликат собственного сообщения** как «Неизвестно».
   - Все остальные участники комнаты гарантированно получают это сообщение с правильным именем автора.

4. **Чистый текст без порчи форматов (POI и карточки контактов):**
   - К тексту сообщений **не добавляются префиксы** канала `[#Channel]` или автора `Имя: `.
   - Гео-метки точек интереса (например, `m:53.247445,34.349876|Точка интереса|poi`) и карточки контактов (`<64hex:type:name>`) остаются валидными и открываются в приложении MeshCore нативно.

5. **Автоматический захват визиток (Contact Cards):**
   - Если в канале появляется карточка контакта `<pubkey:type:name>` или анонс узла (`Advert`), комнатный сервер **автоматически распознаёт публичный ключ и имя** и сохраняет их в энергонезависимую базу узлов (`/nodes.dat`).

6. **Умное разбиение длинных сообщений с защитой UTF-8:**
   - Если сообщение превышает лимит длины пакета комнаты (151 байт), сервер автоматически разбивает его на части `(1/N)` по переносам строк или пробелам.
   - Строгая защита границ многобайтовых символов UTF-8 исключает повреждение русских букв при нарезке.

## 📁 Файлы в папке `bin/`

| Файл | Описание | Адрес прошивки (Offset) |
|---|---|:---:|
| `heltec_v4_channel_room_server-merged.bin` | **Основной заводской образ** (Bootloader + Partitions + App). Предназначен для **flasher.meshcore.io** и ESP Web Flasher. | `0x0` |
| `heltec_v4_channel_room_server.bin` | Образ приложения без загрузчика (для OTA обновления или прошивки поверх существующего загрузчика). | `0x10000` |

## ⚡ Инструкция по прошивке

> [!IMPORTANT]
> Для прошивки полного образа через любой веб-флешер файл **обязательно** должен заливаться со смещением **`0x0`**.

### Способ 1. Через [flasher.meshcore.io](https://flasher.meshcore.io) (Рекомендуемый)

1. Откройте сайт [flasher.meshcore.io](https://flasher.meshcore.io) в браузере с поддержкой WebSerial (**Google Chrome**, **Edge**, **Яндекс.Браузер**).
2. Подключите плату **Heltec LoRa 32 V4** по USB.
3. В списке устройств выберите **Custom Firmware**.
4. Укажите файл **`heltec_v4_channel_room_server-merged.bin`**.
   *(Окончание `-merged.bin` критически важно: сайт распознаёт этот суффикс и автоматически выставляет адрес записи `0x0`).*
5. Подтвердите предупреждение сайта о прошивке объединённого файла (*"You selected custom file that ends with 'merged.bin'..."*).
6. Нажмите **Flash Device** и выберите COM-порт вашей платы. Дождитесь завершения (100%).

---

### Способ 2. Через [Espressif Web Flasher](https://espressif.github.io/esptool-js/)

1. Откройте [espressif.github.io/esptool-js](https://espressif.github.io/esptool-js/) в Chrome/Edge.
2. Нажмите **Connect**, выберите скорость `921600` и подключитесь к COM-порту.
3. В первой строке укажите адрес: **`0x0`** (или `0x0000`).
4. Выберите файл **`heltec_v4_channel_room_server-merged.bin`**.
5. Нажмите **Program** и дождитесь окончания процесса.

---

### Способ 3. Через утилиту `esptool.py` (Командная строка)

Если установлен Python и PlatformIO / esptool:

```bash
esptool.py --chip esp32s3 --port COM9 --baud 921600 write_flash 0x0 heltec_v4_channel_room_server-merged.bin
```
*(Замените `COM9` на ваш COM-порт).*

---

### ⚠️ Что делать, если плата окирпичилась или не определяется

Если при неудачной прошивке порт перестал отвечать, переведите ESP32-S3 в аппаратный сервисный режим (**ROM Bootloader**):

1. Зажмите и удерживайте кнопку **PRG / BOOT** (на лицевой стороне платы возле экрана).
2. Кратковременно нажмите кнопку **RST / RESET**.
3. Отпустите кнопку **PRG / BOOT**.
4. Плата перейдёт в сервисный режим загрузчика и успешно прошьётся любым из способов выше.

## 🛠 Команды управления (CLI)

Команды можно вводить в **Serial-терминале** (115200 baud, окончание строк `CR` или `CR+LF`), через **Serial Console** на сайте [flasher.meshcore.io](https://flasher.meshcore.io), либо удалённо через вкладку CLI в приложении MeshCore (от имени администратора).

### 1. Управление прослушиваемыми каналами (`channel`)

* **Добавить канал для прослушивания:**
  ```text
  channel add <Имя> <Ключ>
  ```
  *Примеры ключей:*
  - Base64 (16 или 32 байта): `channel add Test izOH6cXN6mrJ5e26oRXNcg==`
  - 64-символьный HEX: `channel add Secret F8F42807814D75E67C4E3DBDCDD111FB8856A69610A800112233445566778899`
  - Стандартный публичный канал: `channel add Public default`

* **Показать список настроенных каналов:**
  ```text
  channel list
  ```
  Выводит список каналов, их 1-байтный хэш и префикс секретного ключа для сверки.

* **Удалить канал из прослушивания:**
  ```text
  channel del <Имя>
  ```
  *Пример:* `channel del Test`

---

### 2. Управление узлами и ключами пользователей (`node`)

Сервер автоматически запоминает узлы из визиток, но при необходимости их можно настроить вручную:

* **Добавить узел по визитке (Contact Card):**
  ```text
  node add <3bc2d76d91aff9e0c1ac41da4b3fffc29562062fb8b44882c10da53d1d4f80fb:1:Olejan M>
  ```
  *Можно просто скопировать и вставить визитку контакта из чата целиком.*

* **Добавить узел по имени и HEX-ключу:**
  ```text
  node add "Olejan H1" AAB1DC9BE647D147D5E8FAAD1D3926F4EAE35516EAD5768905F8B031CAB9548F
  ```

* **Список известных узлов:**
  ```text
  node list
  ```
  Выводит сохранённые узлы и их полные 64-символьные публичные ключи.

* **Удалить узел из кэша:**
  ```text
  node del <Имя>
  ```
  *Пример:* `node del Olejan H1`

---

### 3. Стандартные команды сервера комнат

* `room.post <текст>` — опубликовать системное сообщение в комнату от имени сервера.
* `get acl` — просмотреть список авторизованных клиентов и их права.
* `setperm <64hex_pubkey> <права>` — назначить права клиенту (1 = Admin, 2 = Чтение/Запись, 0 = Только чтение).
* `get radio` — показать текущие параметры радиоканала (Частота, Полоса, SF, CR).
* `stats-packets` — статистика принятых/переданных пакетов.
* `stats-radio` — уровень шума эфира (noise floor), RSSI и SNR последних пакетов.
* `ver` — версия прошивки и дата сборки.
